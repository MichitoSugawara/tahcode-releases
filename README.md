# tahcode-releases

Public **desktop installers** for [tahcode](https://tahcode.com).

- Source code stays private in [`MichitoSugawara/tahcode`](https://github.com/MichitoSugawara/tahcode).
- This repo only publishes GitHub Releases (`desktop-v*`) with signed macOS `.dmg` / `.zip` (and related update metadata).
- The tahcode desktop app checks updates against this repository.
